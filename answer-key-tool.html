🔑 Answer Key Tool

Push an answer key straight to the protected AnswerKeys sheet — works for any IELTS or TOEIC test set, now or in the future.

1. Test Details
Find the Test Set ID in admin.html → Test Sets panel (or create the test set there first if it doesn't exist yet).
2. Listening Answers
Paste answers in "number.answer" format, in any order, separated by spaces or newlines — e.g. 1.A 2.C 3.B or one per line. Answers can be single letters, whole words, or short phrases (e.g. 21. NOT GIVEN, 5. New York) — not just multiple choice. Numbers should run 1–40 (IELTS) or 1–100 (TOEIC).
Multiple acceptable answers: separate alternates with a slash, e.g. 6.MOVIE/FILM or 40.PRACTICE/PRACTISE — these will be saved together so either answer counts as correct.
